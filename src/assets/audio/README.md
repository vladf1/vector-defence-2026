# Audio Assets

The `.m4a` files in this folder are committed game assets and are the source of truth for runtime sound effects.

The sounds are derived from Kenney CC0 audio packs:

- Sci-fi Sounds: https://kenney.nl/assets/sci-fi-sounds
- Digital Audio: https://kenney.nl/assets/digital-audio
- Interface Sounds: https://kenney.nl/assets/interface-sounds

They were converted to AAC `.m4a` files with local tooling and trimmed for game use.
